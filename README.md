## Open source I maintain

**[SysKnife](https://github.com/lacs-project/sysknife)**: an MCP server and CLI that let an AI agent administer Linux through typed, approval-gated actions. The model picks an action, a policy-enforced daemon builds the command, and every change lands in an Ed25519-signed audit log. Written in Rust.
